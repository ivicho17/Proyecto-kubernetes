# Despliegue de una aplicación en Kubernetes

Orquestación y despliegue de una aplicación en un **clúster de Kubernetes** mediante manifiestos declarativos (Deployments y Services). Práctica de infraestructura y contenedores.

## 🎯 Qué demuestra

- Definir el **estado deseado** de una aplicación de forma declarativa con manifiestos YAML.
- Desplegar la aplicación en un clúster mediante **Deployments** (réplicas, estrategia de actualización).
- Exponer la aplicación con **Services** (comunicación interna y acceso al servicio).
- Conceptos base de orquestación: pods, réplicas, autorreparación y escalado.

## 🔒 Relevancia para seguridad

La orquestación de contenedores es parte central de las infraestructuras modernas. Entender cómo se despliega y expone una aplicación en Kubernetes es la base para después **bastionarla**: políticas de red, gestión de secretos, control de acceso (RBAC) y límites de recursos.
